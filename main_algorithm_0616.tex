    \section[项目经历]{\makebox[\iconwidth][c]{\color{primarycolor}{\faProjectDiagram}}\quad 项目经历}

    {\large \textbf{智能数据分析问答助手（校企合作项目） \quad 项目主要成员}} \hfill 2025.10--2026.02
    \begin{itemize}
        \item \textbf{项目目标}：面向药品采购、零售、库存等全链路数据，建设基于 LLM 的医药供应智能数据分析问答助手，将业务人员的自然语言问题转化为可执行 SQL 与分析结果；负责 LLM 应用架构、RAG 知识库与 Text-to-SQL 质量优化。
        \item \textbf{RAG 与 Schema 检索}：基于 Dify/LangChain 完成 LLM 工程化部署，使用 Milvus 构建外部知识库；对数据字典进行元数据增强，将表名、字段名、字段含义和常见枚举值拼接为富文本后向量化，并结合 HNSW 索引与标量过滤提高多表关联、专业术语和时间/分类条件的召回精度。
        \item \textbf{Text-to-SQL 自修正}：设计规则化问题分类、样例对、CoT 和约束 Prompt，引导模型生成 SQL；引入 SQL 试执行与 Self-Correction 机制，捕获 MySQL Error Message 后回传给 LLM 反思重写，最多重试 3 次，将 SQL 执行成功率由约 70\% 提升至 90\%+。
        \item \textbf{评估与防幻觉闭环}：联合业务问题构建约 500 条 Golden Dataset，使用 RAGAS 的 Context Recall/Faithfulness 与 Execution Accuracy 评估检索和 SQL 结果；设置相似度阈值、低置信拒答策略和人工反馈 Bad Case 回流，降低无依据回答与错误数据展示风险。
        \item \textbf{项目成果}：支撑校企合作项目交付与竞赛展示，获得重庆市人工智能大赛市级银奖；核心链路形成“检索评估--SQL 自修正--人工反馈”的质量闭环，SQL 执行成功率提升至 90\%+。
    \end{itemize}

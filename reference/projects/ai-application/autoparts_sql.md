# 汽车配件表格问答系统（Text-to-SQL）

> 岗位适配：**首选** 算法（LLM 微调 / 强化学习 / Text-to-SQL）、AI 应用开发；**次选** NLP 算法、大模型应用工程师

> 理由：Qwen2.5 SFT + RL 训练、Function Calling、案例检索，是本项目中「模型训练侧」最重的项目，更适合算法岗；投 AI 应用岗时则突出工具调用与多模型协同。

- **时间**：2025.03--至今（待确认）
- **角色**：负责人
- **技术栈**：Qwen2.5、SFT、RL、Tools / Function Calling、RAG、Text-to-SQL

## 项目简介

面向汽车配件表格查询场景，构建本地化表格问答机器人，将用户自然语言问题转化为 SQL 查询，并对数据库结果进行摘要与解释，降低业务人员直接编写 SQL 的门槛。

## 主要工作

- **模型训练与增强**：采用 Qwen2.5 作为基线模型，基于有标签数据进行 SFT，并引入无标签数据开展强化学习训练，提升模型对表格问答、字段约束和业务表达的理解能力。
- **工具调用与案例检索**：为模型配置数据库查询相关 Tools/Function Calling，并针对特例编写 Function；沉淀“问题--SQL--CoT”案例对并进行本地嵌入，用户提问时召回相似案例作为生成参考。
- **多模型协同**：接入表格生成模型、低成本聊天模型等特定任务模型，按任务类型分流模型调用，支撑 SQL 查询、结果总结和表格生成等多类业务需求。

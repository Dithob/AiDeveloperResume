# 多模态家电识别与知识库入库系统

> 岗位适配：**首选** AI 应用开发 / LLM 应用开发、多模态应用方向；**次选** 后端（具备 AI 服务封装 / vLLM / FastAPI 经验）、算法（多模态）

> 理由：OCR/视觉大模型 + Dify 多 Agent 编排 + vLLM 推理服务化 + FastAPI 封装，覆盖「多模态识别 → 服务化落地」全链路，是 AI 应用 + 工程交付结合的代表项目。

- **时间**：2025.06--2025.09
- **角色**：项目主要负责人
- **技术栈**：Dify、Docker/Miniconda、OCR / 视觉大模型、vLLM、FastAPI、Query Rewrite、Prompt 模板

## 项目简介

面向家电售后知识库建设场景，针对图片/OCR 识别信息不完整、长尾产品文本特征稀疏和重复入库问题，设计“识别--补全--校验--去重--入库”的自动化流程，降低人工录入和知识维护成本。

## 主要工作

- **识别与字段补全**：使用 Docker/Miniconda 统一部署 OCR/视觉大模型环境，基于 Dify 编排“图片识别--联网搜索--字段抽取--置信度校验”多 Agent 流程；结合 Query Rewrite 和动态 Prompt 模板补全品牌、型号、规格、品类等产品字段。
- **服务封装**：接入 vLLM 优化模型推理服务，并使用 FastAPI 封装识别、补全、去重和入库接口，统一对外提供可复用能力，支撑商品手册、维修手册和客服知识库的持续更新。
- **业务落地**：构建了 1000+ 类家电产品的自动入库工作流；通过向量匹配、规则校验和二次补全的去重策略，缓解了版本迭代导致的知识冗余，降低了人工录入与重复维护成本，为下游客服问答与检索系统搭建了高质量的数据基础。

# 校园二手交易平台

> 岗位适配：**首选** 前端开发 / 全栈（Django 方向）；**次选** Web 应用开发

> 理由：页面交互 + Django 模板复用 + 后端 API 与 SQLite 建模，是「前后端都碰」的全栈入门项目；技术深度弱于云端图像协同 / 智能应用生成平台，宜作为补充项目或初级岗投递。

- **时间**：2025.03--2025.06
- **角色**：项目负责人
- **技术栈**：Django、SQLite、响应式布局

## 项目简介

面向校园二手交易场景，开发支持商品发布、商品浏览、关键词搜索与交易流程的信息平台，覆盖用户、商品与交易等核心实体管理。

## 主要工作

- **页面与交互实现**：负责商品列表、商品详情、商品发布和搜索结果等核心页面开发，围绕列表渲染、条件筛选、表单提交和状态提示组织前端交互逻辑；基于响应式布局适配不同屏幕尺寸。
- **模板复用与数据流打通**：使用 Django 模板引擎抽取页面公共结构，实现导航、商品卡片、列表区域等模块复用；参与后端 API 设计与 SQLite 实体关系建模，打通商品数据展示、提交、查询和交易状态流转。

# 催收策略效果评估（机器学习）

> 岗位适配：**首选** 算法（机器学习 / 风控 / 数据挖掘方向）；**次选** 数据分析 / 数据平台

> 理由：LightGBM 建模 + SHAP 可解释性 + 业务评估闭环，是传统 ML 项目，最契合算法（风控/推荐）岗；与 AI 应用、前后端岗相关性较弱。

- **时间**：2024.03--2024.05
- **角色**：负责人
- **技术栈**：LightGBM、SHAP、归因分析

## 项目简介

面向贷后催收历史数据和客户画像，构建催收策略预测与效果评估平台，将复杂业务诉求拆解为多分类预测、策略推荐与特征归因分析任务。

## 主要工作

- **建模方案**：基于 LightGBM 集成学习算法构建预测模型，整合信用历史、消费行为、动态账单等多维特征，输出不同客户群体下的催收手段决策建议。
- **可解释性分析**：引入 SHAP 可解释性框架，对影响催收策略效果的关键因子进行特征归因，生成可解释的策略影响报告，辅助业务侧理解模型决策依据。
- **业务评估闭环**：围绕模型预测结果与策略归因结果形成评估闭环，为催收策略制定、调优和复盘提供数据支撑。

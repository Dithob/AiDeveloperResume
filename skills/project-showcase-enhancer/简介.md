夫良玉韫椟，待良工而后彰其华；宝剑藏匣，遇识者而始显其锋。今之开发者，多能运斤成风，俄顷立一项目；然藏器于身而莫之能言，怀璧在握而难自陈其价。是以码虽精而人未之知，Demo 虽巧而市未之售。善作者不必善述，此古今之通患也。

本智能体技能，正为此患而生。

## 这是什么

**个人项目展示增强器（Project Showcase Enhancer）** 是一个面向开发者与求职者的智能体技能（Agent Skill）。它不止于「扫一遍代码吐模板」，而是一套**人机协作的工作流**：先读懂你的代码与原始意图，再与你共创，把能跑的 Demo 推演成商用级产品方案，最终产出两份可直接使用的文档——**项目展示文档**与**面试备考手册**。

## 它解决什么痛点

你是一个**马上要去面试的程序员**，卡住的不是"会不会写代码"，而是"怎么把代码变成入场券"：

- **简历项目栏写不出彩**：代码能跑，项目经历却只会写「基于 React + Node 做的博客」，提炼不出技术深度与业务价值；
- **个人网站的项目展示模块写不好**：作品集站点做好了，项目详情页空泛，像把 README 照搬一遍；
- **拿到 JD 不知面试官怎么追问**：心仪岗位的 JD 摆在那，却缺一套 **JD 驱动的模拟面试**提前演练；
- **项目不够亮眼，需要合理包装**：真实项目可能没那么"高大上"，你要的是基于事实把亮点放大、讲专业，而不是编造；
- **想偷师别人的真实面试表现**：抖音上大量 UP 主分享真实面试口播，但没人帮你系统拆过——到底问了什么、怎么答才惊艳；
- **面试露怯**：面试官一追问技术选型理由、架构权衡，便无从应答，准备毫无抓手。

本智能体技能把这几件事一次性解决：**读懂自己代码 → 偷师真实面试 → 推演 / 包装项目 → JD 模拟面试对练 → 沉淀一问一答题库**。

## 四大模式（四模式闭环）

1. **深度代码理解（模式 A）**：脚本 `scan_project.js` 秒级输出结构化 JSON（技术栈 / 依赖 / 带职责标注的目录树 / 入口与配置文件 / README 原文）；`deep_analyze.py` 进一步做 AST 级分析（架构风格 / 调用图 / 数据流 / DDD 模式 / 圈复杂度高危点）。大模型据此精读关键源文件，解释模块划分、数据流、启动流程，并从 README 提取产品原始意图——**让你用 AI 看到项目更深一层**。
2. **商用级推演与合理包装（模式 D）**：通过多轮对话澄清目标用户、核心卖点、商业模式（可选）与 MVP 范围；列出三类差距（功能 / 工程化 / 运维，每项标 P0/P1/P2 优先级）；给出三阶段演进路线图（MVP → 完善 → 商用）。推演内容明确标注"规划中"，**基于事实放大亮点、绝不编造**。
3. **项目展示文档**：按 `assets/showcase-template.md` 模板填充亮点、功能模块、技术栈选型理由、架构设计、部署说明，排版精良，可直接放进简历、个人网站项目展示模块或作为 README。
4. **JD 驱动模拟面试 + 题库沉淀（模式 D + B + C）**：结合目标岗位 JD 与简历，生成**角色扮演式模拟面试**——面试官视角出题（必问 / 针对性 / 追问三层）+ 候选人视角推荐答法 + STAR 素材 + 连环追问链，把「被问住」变成「有备而来」；同时可把抖音真实面试视频拆成一问一答、连同自产面试题一起沉淀进「面试绿皮书」（长期题库），跨会话持续复习。

## 核心设计：混合架构

> **脚本提供确定性地图，大模型在地图上做深度推理——两者结合，既快又准，也省 token。**

- 扫描脚本（硬编码字典，不调模型）：确定性强、速度快、零 token 消耗，先画出「地图」；
- 大模型语义理解：只在地图之上做只有 LLM 能做的深度推理；
- 你不是「替换」某个单一工具，而是把「读代码 → 推演商用 → 写展示 → 备面试」四步一次性跑通。

## 适用人群

- 在校生 / 应届生：做作品集、备春招秋招；
- 转岗 / 跳槽者：把过往项目包装到位；
- 独立开发者：把 side project 推向商用；
- 技术博主 / 讲师：沉淀项目讲解稿与案例。

## 上手与依赖

- 零编译、零强制依赖：触发即用自然语言，如「分析一下我的项目」「帮我把这个项目推演到商用」「结合我的 JD 准备这个项目的面试」。
- 可选：解析简历文件需 `pip install pdfplumber python-docx pypdf`；代码扫描依赖 Node 环境。
- **推荐在高推理模型下使用**（Claude Opus 4.6 / DeepSeek v4 Pro / GPT-5.6 或同级），低推理模型会导致理解肤浅、推演模板化、面试题预测质量差。

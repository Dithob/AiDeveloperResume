    \projectheading{腾讯地图 UI 自动化测试 Agent}{参与框架建设}{2026.06--2026.09}
    \begin{itemize}
        \item \textbf{Agent 系统架构与多智能体编排}：构建 LLM Agent 质量效能体系，按职责五层编排 13 个 Skill 与 3 个自研 MCP 服务，打通从自然语言需求到自动化用例生成，再到知识沉淀的闭环；联动 TAPD/Figma 从需求自动生成可执行 case.py，单用例生成约 10--15 分钟（手写需 1--2 小时），覆盖 17 个业务域、600+ 生成代码单元。
        \item \textbf{MCP 工具开发与多模态感知}：开发设备控制与线上诊断 MCP，接入腾讯地图 MCP 动态解析构造测试数据；融合四层UI视觉感知，链式降级解决自绘控件无资源id的定位问题；scrcpy 长连接投屏截图从约 1s 降至 50ms。
        % \item \textbf{MCP 工具开发与多模态感知}：自研设备控制 MCP 与线上失败诊断 MCP，接入腾讯地图官方 MCP 动态解析坐标构造测试数据；融合 UIAutomator、OCR、OmniParser、OpenCV 四层感知，链式降级解决自绘控件无 resource-id 的定位问题；scrcpy 长连接投屏将截图耗时从约 1s 降至 30--100ms。
        \item \textbf{知识工程与语义检索}：设计纯文件知识图谱，基于 23 个研发仓库 UI 索引做同源静态推理，让 Agent 生成前先检索理解研发代码；以 AST 三道闸扫描 1500+ 私有 helper，结合 jieba + BM25 实现公共方法语义检索与经验回流复用，解决规模化生成时的重复造轮子问题。
        \item \textbf{可靠性工程与自愈闭环}：以意图锁定、门禁探索、九维度自审等护栏机制保障生成质量；通过 Lint 门禁与逐步断言保证代码稳定，以 health 回测通过率淘汰 flaky 用例；失败后基于证据包自动再生成补丁形成 Self-heal 闭环。
    \end{itemize}
